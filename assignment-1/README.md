# Personal Portfolio (v1) — Assignment 1

## Project Overview
This repository contains the plain HTML structure for my personal portfolio webpage, built as part of the Web Development course assignments. The goal of this assignment is to establish a strong foundation using semantic HTML5 markup, structured text, internal links, lists, and images before adding CSS styling.

## Key Features & Requirements Implemented
- **Semantic HTML Structure:** Structured using standard HTML5 tags including `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **Internal Navigation:** Working anchor links (`<a href="#id">`) allowing smooth jumps to different sections (`Home`, `About`, `Skills`, `Projects`, `Contact`).
- **Lists:** 
  - Unordered lists (`<ul>`) for Skills, Education, and Club activities.
  - Ordered list (`<ol>`) for the learning sequence.
  - Definition list (`<dl>`) defining core web development terms (HTML & CSS).
- **Media & Accessibility:** Profile photo and project preview images included with descriptive `alt` text.
- **Meta Tags:** Document metadata configured with `charset`, `viewport`, `description`, and `author`.
